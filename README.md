# 九牧马桶 → 华为智慧生活

面向九牧 `JOMOO_SMART_249734` 的本地蓝牙适配与 Home Assistant / 华为智慧生活桥接实验。项目处于实机验证阶段。两台真实翻盖入口已出现在鸿蒙智慧生活，主卫从手机发起开盖、关盖已实际执行并回读确认；独立后台蓝牙权限已在用户重启后生效，防火墙规则和完整控制恢复仍待处理。

目标是在保留原设备与九牧智联小程序的前提下，为每台马桶提供独立、可验证的控制入口。公开型号表和用户提供的照片对应 `ZD6450-SA`；兼容范围仅限本次验证的型号和功能。

## 当前路线

1. 在 Apple Silicon Mac 上运行 ARM64 Home Assistant OS 虚拟机。
2. 使用虚拟实体验证华为桥接的发现、绑定、命令路由和重启恢复。
3. Mac 上运行鉴权 BLE 网关，使用固定设备身份、新鲜状态、单次动作与持久化去重。
4. 将已验证的功能导出到智慧生活；S2、Mini、小艺与场景分别验收。

华为社区桥接当前以开关面板映射按钮等实体，不保证原生马桶卡片。本项目与官方九牧/华为产品无隶属关系。

## 当前可用范围

- 主卫开盖/关盖、客卫开盖已做现场动作确认；手机入口的验收进度见现场记录。
- 远程仅开放翻盖，落座状态只在 HA 中读取；温度、清洗、烘干、冲水等未开放。
- 已知设置做回读比较；未知 `FA.p5.bit0` 变化单独报告，不宣称完整协议已验证。
- 用户重启后独立后台网关已获蓝牙授权并成功读取两台；防火墙仍阻止其传入连接，手机控制恢复待验证。
- 华为兼容库目前安装在 Core 容器内，更新/重建容器可能导致桥接失效。

## 扫描

macOS 已开启蓝牙且授予终端蓝牙权限后，在仓库根目录执行：

```sh
mkdir -p work
swift tools/scan_jomoo.swift > work/scan.json
```

只扫描九牧广播，不连接或控制设备。扫描结果中的 macOS UUID 不等于 Linux/ESPHome 使用的蓝牙 MAC。多台设备名称相同，禁止按每次最强信号自动选择控制对象。
