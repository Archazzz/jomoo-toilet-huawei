# 单卡片马桶桥接实验

本目录方案尚未完成华为云端注册和手机页面验收，不能标为可用的原生马桶集成。现场仍通过原桥接控制翻盖。

## 当前证据

用户在智慧生活手动搜索未找到 ZD6450。九牧小程序设备信息显示名称 `ZD6450-SA`，该页面没有展示联网模块，不能仅凭缩写证明与官方 `ZD6450-SA-CJM305` 是同一联网版本。官方 `2QBR` Profile 声明 Wi-Fi，现场已确认的是私有 BLE 控制；官方直连仍未确认，不执行出厂重置来试错。

备用方案在一个 OneConnect 子设备内绑定多个服务。两台马桶对应两个 child，每个 child 的所有服务绑定自身同一个 HA 翻盖实体。示例见 [mapping.example.json](../deploy/oneconnect/mapping.example.json)，JSON 可由上游 YAML 解析器读取；示例默认禁用、实体为占位符。

已实现 `offSeatAction`、`toiletLidStatus`、`seatStatus`、`toiletSetting`、`drySetting`、`washSetting`、`seatHeating` 七项服务。现阶段仅允许 `offSeatAction.action=3/4` 的翻盖操作，其余服务仅上报已知数据。未知档位不默认成零，尤其座温最高档 `100` 未建立 BLE 映射。光感夜灯、自动翻盖在此 Profile 中是只读字段，不能宣称原生页面可写。

HA 翻盖实体附带该设备的状态、动作白名单和明确过期时间，不包含蓝牙身份或网关令牌。服务读取仅接受本型号标记、可用实体和未过期状态；未知或运动中的盖圈组合不上报为稳定位置。命令按绑定实体路由，校验严格字段、数值类型和动作白名单。HA 接到命令后仍经本地网关执行新鲜状态检查、单次写入、回读和持久化去重。

## 可复现构建

下载 `research/oneconnect-source-lock.json` 中固定提交的上游源码到忽略目录，不安装浮动 main。构建器对组件的全部文件和 LICENSE 校验 SHA-256，拒绝缺失、额外或修改后的源文件；输出目录必须不存在。

```sh
python tools/build_oneconnect.py \
  --upstream work/upstream/oneconnect-95b63b78ae49 \
  --output work/staged/oneconnect-build
```

产物包含 `custom_components/jomoo_local`、`custom_components/oneconnect_bridge` 和构建摘要。保留上游许可证及本地修改说明；构建动作不接触运行中的 HA。初始映射为空，不自动注册上游默认的汽车测试模型。

对固定版本做了以下局部修改：

- 注册本项目七项服务适配器，重复 sid 立即失败。
- 在回复云端之前调用只读命令校验；未绑定、未实现、过期或禁用的命令不进入动作分发，返回非零 `errcode=1`。实际智慧生活对此错误码的呈现仍未验证。
- 合法命令的早期 ACK 仅代表接受，不代表动作完成；真实状态仍由回读更新。延长 HA 命令等待上限至 110 秒以覆盖本地网关的等待与操作上限，超时取消本次 HA 协程，不自动重试。
- 声明 `jomoo_local` 依赖，并去除默认无关子设备。

此次实验仅允许带命令预检接口的服务下发控制；不要把该构建当作其他品类的通用桥接升级。

## 已执行的隔离检查

在 HA Core 的实际 Python 环境中，将产物放在独立临时目录，运行：

```sh
python /config/check_oneconnect_build.py --build /config/jomoo_staging/oneconnect-build
```

检查脚本来自 [tools/check_oneconnect_build.py](../tools/check_oneconnect_build.py)，使用假的 HA 实体、服务和云端客户端；不会调用运行中的 HA 服务，不会发起配对或蓝牙动作。已验证模块能加载、两台各七服务映射能解析、初始映射零子设备、正确目标路由，以及不支持命令在分发前被拒绝并生成非零响应。本地另有适配器测试覆盖过期、缺失、异常类型和其他设备隔离。

## 真实迁移前仍需验证

1. 当前桥接和新桥接都使用 UDP 5683，不能同时启动配对监听；先备份原集成及 `.storage`，安排短时停止旧监听，再由用户完成新网关绑定。
2. 用一个子设备验证 `2QBR` 的注册参数、页面加载和服务实际请求。官方 Profile 存在不保证允许用社区网关注册，也不保证页面在只提供部分服务时可用。
3. 核对离线呈现、状态过期与动作错误提示。适配器不报假状态，但云端缓存与页面显示需实测；不能据此宣称云端离线已处理。
4. 首次机械动作仅使用主设备和已验证翻盖。更多功能须逐项完成实机验收；温度、冲水、清洗、发泡等尚未开放。
5. 新卡片验收完成后再迁移原入口与场景引用，最终每台物理设备只保留一张正式卡片。旧绑定数据在迁移期间保留以便恢复；不能用 HA 分组冒充华为卡片已合并。
