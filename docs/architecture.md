# 架构与验收

## 分层

```text
智慧生活 / 小艺 / 中控屏（分别验收）
                ↕
华为社区桥接（Linux aarch64 / amd64）
                ↕
Home Assistant（Mac 上的 ARM64 HAOS 虚拟机）
                ↕
按型号适配的九牧控制层
                ↕
Mac 本机 BLE 网关（已部署；外部 BLE 代理未部署）
                ↕
明确绑定的九牧设备 A / B
```

华为产品身份和卡片能力与九牧 BLE 协议是不同层。桥接支持开关不等于支持原生马桶品类；App 可控也不等于全屋断网场景可控。

一台物理设备对应一张华为正式卡片是产品约束。按功能创建 HA 实体可以保留，但新增实体不得自动导出为独立子设备。优先核对官方 `2QBR` 的直接配网兼容性；若不能直连，再验证 OneConnect 单子设备多服务方案。后者需要匹配 Profile 的适配器和真实注册验收，不能只改产品编号即宣称支持。

## 实施关卡

| 阶段 | 通过条件 |
|---|---|
| A：华为入口 | 无物理效果的虚拟实体可绑定、控制；HA 重启 3 次后仍保持身份与绑定 |
| B：设备识别 | 明确每台身份；枚举 GATT；状态回包满足型号、长度与校验规则 |
| C：最小控制 | 一次操作对应一次动作或设置；新状态回读一致；已知设置不变，未知字段变化明确报告 |
| D：双设备 | 并发请求不会串控；手机小程序占用时合理失败；断线不重放机械动作 |
| E：稳定性 | 虚拟机和 Mac 重启恢复；72 小时观察；中控屏、语音、远程、断网分别记录 |

尚未完成的关卡不得在 README 或用户界面标记为支持。

## 重启与持久化

使用同一虚拟机磁盘、网络身份和 HA 配置目录，保留桥接的 `.storage` 数据。系统启动、用户解锁、虚拟机启动、HA 启动、桥接恢复是不同环节；只配置登录项不能保证登录前运行。

Mac 关机时新增控制与 HA 自动化中断，原有马桶功能不依赖它。恢复后先读取新状态，不补发停机期间的冲水或翻盖。FileVault 解锁和系统休眠应在部署验收中核对，不自动关闭安全功能。

蓝牙连接是临时会话。按需连接后及时释放，避免长期占用官方小程序的连接。不可用或过期状态应标为未知，不能沿用旧值伪装在线。

## 命令边界

- 扫描：仅接收广播。
- GATT 枚举：连接与发现服务/特征，不发送业务帧。
- 状态查询：在 BLE 层写入经过确认的查询帧，无预期物理动作。
- 设置：读本次连接的新状态，只改变已验证字段，回读已知设置；未解释的配置位不盲目覆盖。已观察到的未知动态位变化单独报告。
- 机械动作：显式目标、去重、一次发送；未知结果不自动重试。
