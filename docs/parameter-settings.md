# 参数设置适配（尚未实机验收）

`automatic_lid_on/off` 和 `automatic_night_light_on/off` 已实现协议编码、目标回读与 HA 开关定义。分别表示自动感应翻盖和光感夜灯设置，不代表立即翻盖或强制亮灯。这两项设置没有发送现场写命令；官方原生 Profile 对应只读字段，因此当前不开放它们的写入口。其他温度、幅度、除臭和落座发泡设置的最新验证见[多功能扩展](expanded-controls.md)。

## 协议边界

- 自动翻盖使用 FA 第 0 字节 bit 3；光感夜灯使用第 2 字节 bit 7，字节均从 0 编号。
- 设置命令为 `0x19`；依据本次连接的新鲜 FA/E9/EA 构造参数，复用已有保留字段编码，仅修改目标位。行为线索来自固定版本的公开参考，未复制其代码。
- 落座、工作中、机构运动、故障及未验证配置位仍拒绝控制。
- 回读检查目标位、盖圈位置和其余已知设置；未知动态位沿用原报告机制。开启自动翻盖后若设备感应导致盖板移动，不能当作设置稳定完成，也不重发设置。
- 不使用华为 Profile 的读写定义推断 BLE 位值；两套协议分别核对。水温、座温、风温另有经过参数往返回读的实现，不属于本页两项待验证设置。

## 后续验收

仅在主设备进行：先记录小程序和只读状态，对单个设置进行一次修改，核对小程序、实际行为和回读，再由明确操作恢复原值。过程中不落座，开启自动翻盖时避免靠近触发感应。新增协议先完成合成验证；开放待验收入口时标明实际验证范围，不把入口可点等同于功能已实测。

HA 的所有功能实体归属同一物理设备。现已通过原生产品页面与多服务子设备实现单张卡片，所有后续功能沿用这一结构。HA 设备分组本身不保证华为卡片合并。
